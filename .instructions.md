# Robot FTP Extension - Development Guidelines

## Quick Overview
This is a VS Code extension that provides FTP file management for **Fanuc TP robots**. Users can upload/download `.LS` files directly from VS Code using context menus and commands.

**Version source**: `package.json` (currently `0.7.0-dev`) | **Main File**: `src/extension.js`

Read `AGENTS.md` and `.agents/HANDOFF.md` for the current handoff. Feature-specific guidance is in `.agents/LSVerifier.md`, `.agents/RenameLS.md`, and `.agents/QualityAssurance.md`. Release commands and historical notes are in `.agents/DocumentationRelease.md`.

## Architecture Quick Reference

### Core Functions (src/extension.js)
- **FTP Operations**: `f_uploadToRobot()`, `f_downloadFromRobot()`, `f_updateFilesFromRobot()`, `f_updateSelectedFileFromRobot()`
- **IP Management**: `getRobotIp()` - uses persistent ip.txt file, validates IP format
- **CSV Descriptions**: `loadDescriptions()`, `watchCSVFile()` - loads Key→Description pairs
- **Inlay Hints**: Anonymous provider in `activate()` - matches DO[], DI[], R[], F[] patterns

### Extension Activation
- **Trigger**: Workspace contains `*.ls` files
- **Main Entry**: `src/extension.js` → `activate()` function
- **Config**: All commands, keybindings, language support in `package.json`

## How to Add Features

### ✅ Adding a New Command
```javascript
// 1. Create function
async function myNewFeature(param) {
  try {
    // your code
  } catch (error) {
    vscode.window.showErrorMessage(`Error: ${error.message}`);
  }
}

// 2. Register in activate()
const myCommand = vscode.commands.registerCommand('extension.myNewFeature', myNewFeature);
context.subscriptions.push(myCommand);

// 3. Add to package.json
"commands": [{
  "command": "extension.myNewFeature",
  "title": "My New Feature"
}]
```

### ✅ For FTP Operations
- **Always reuse** `getRobotIp(directoryPath)` to get robot IP
- **Use try/catch** with vscode.window.showErrorMessage() for errors
- **Log to outputChannel** for debugging: `outputChannel.appendLine('message')`
- **Set binary mode** before upload/download: `await client.send("TYPE I")`

### ✅ CSV/Descriptions
- Format: `Key,Description` (two columns)
- Keys are case-insensitive (converted to lowercase)
- File path: User can select custom path or use default `descriptions.csv`
- File watcher auto-reloads on changes

## Code Patterns

### Pattern: FTP Connection with Timeout
All FTP operations use `withRobotConnection()` helper which includes:
- **Automatic timeout:** 10 seconds - prevents hanging if robot is unresponsive
- **Try/finally guarantee:** Client always closes, even on error or timeout
- **Centralized config:** Uses `getRobotConfig()` for port/username/password

```javascript
await withRobotConnection(directoryPath, 'OperationName', async (client, ipAddress) => {
    // Your FTP operation here
    const fileList = await client.list();
    // client.close() handled automatically by helper
});
```

**Timeout behavior:**
- If robot doesn't respond within 10 seconds → Error message "Connection timeout"
- User can retry or check robot connectivity
- Connection is cleaned up automatically

### Pattern: File Type Filtering
```javascript
// Filter by extension or wildcard
if (fileType === "*" || file.name.toLowerCase().endsWith(fileType.toLowerCase())) {
  // process file
}
```

### Pattern: Date-Stamped Folders
```javascript
const today = new Date();
const folderName = `${today.getFullYear()}-${String(today.getMonth() + 1).padStart(2, '0')}-${String(today.getDate()).padStart(2, '0')}_01`;
```

## Configuration Management

### VS Code Settings (robotFtp)
The extension uses VS Code settings for FTP connection parameters:

```javascript
function getRobotConfig() {
    const config = vscode.workspace.getConfiguration('robotFtp');
    return {
        port: config.get('port', 9125),
        username: config.get('username', 'Administrator'),
        password: config.get('password', '')
    };
}
```

### Available Settings
| Setting | Type | Default | Purpose |
|---------|------|---------|---------|
| `robotFtp.port` | number | 21 | FTP port (21 standard, 9125 for RoboGuide) |
| `robotFtp.username` | string | "Administrator" | FTP login username |
| `robotFtp.password` | string | "" | FTP login password |

### User Configuration Example
Users add to `.vscode/settings.json`:
```json
{
    "robotFtp.port": 21,
    "robotFtp.username": "Administrator",
    "robotFtp.password": ""
}
```

**For RoboGuide:**
```json
{
    "robotFtp.port": 9125,
    "robotFtp.username": "Administrator",
    "robotFtp.password": ""
}
```

### When Adding New Settings
1. Define in `package.json` under `contributes.configuration.properties`
2. Create getter function (like `getRobotConfig()`)
3. Use in feature code instead of hardcoding
4. Document in README.md

## Known Patterns & Issues to Avoid

❌ **Don't** hardcode IP addresses outside of default  
✅ **Do** use `getRobotIp()` function for all robot connections

❌ **Don't** forget to close FTP client connections (`client.close()`)  
✅ **Do** wrap in try/finally if needed: `finally { client.close(); }`

❌ **Don't** use relative paths for cross-platform compatibility  
✅ **Do** use `path.join()` for all path operations

❌ **Don't** forget "TYPE I" (binary mode) before file transfers  
✅ **Do** set binary mode explicitly for reliability
